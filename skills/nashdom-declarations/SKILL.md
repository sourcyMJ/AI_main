# Сбор деклараций с наш.дом.рф

## Работает ровно один способ — Claude in Chrome

Порядок:

1. Открыть карточку `/сервисы/каталог-новостроек/объект/{ID}` в **обычном
   Chrome** (не headless, не через автоматизацию).
2. Выполнить `GRAB_JS` — собирает из DOM ссылки вида
   «Проектная декларация … DD.MM.YYYY».
3. Скачать по `/api/ext/file/{HEX}?filename=…` **в той же вкладке**.

Эталонная реализация — `voskhod_pd/voskhod_pd_pipeline.py`: функции
`GRAB_JS`, `save_links`, `download_js`, `import_downloads`. В `gorn_pd/`
те же функции.

За этим способом стоят реальные загрузки: все месяцы Горна с мая по
сентябрь 2026 и 2Q26 Восхода.

## Что не работает — проверено, не изобретать заново

| Попытка | Ответ сайта |
|---|---|
| `curl` к страницам и к API | 403 |
| Любой headless-браузер | 403 |
| API `/document/rpd` из Playwright | Заглушка и блокировка карточки |

WAF блокирует **признаки автоматизации**, а не адрес и не географию.
Поэтому ни отдельный сервер, ни арендованная VM, ни облачный контейнер
проблему не снимают: дело не в том, где стоит машина, а в том, что
браузер не живой.

## Пустой список ссылок — это не блокировка

Это промах рендера Angular-SPA: страница ещё не дорисовалась. Нужно
**повторить**, а не переписывать код сбора. Именно на этой развилке
Playwright трижды возвращался в кодовую базу.

## Playwright для наш.дом.рф удалён и возвращать его не надо

`download_declarations()` в Горне против сайта не прогонялась вообще, а
`scrape/kapelskiy2/pd_fetch.py` и `scrape/siti2/pd_fetch.py` были её
копиями с ложной пометкой «метод проверенный». Данные для тех отчётов на
деле собирались через Claude in Chrome. Все три места удалены.

**Исключение:** ЕРЗ.РФ — другой сайт, там Playwright работает и нужен
(`scrape/erz_parser.py`). Его не трогать.

## Ритм расчётов

- **Горн** — ежемесячно. Отчёт за месяц M считается по декларациям месяца
  **M+1**. Цена кв.м = прирост эскроу-суммы / прирост эскроу-площади.
- **Восход** — ежеквартально. Сверка строго по блоку своего корпуса,
  окно выбора пары деклараций 1–12 с приоритетом одинакового дня.

Перед работой с любым из них читать его `README.md` первым — оба написаны
как самодостаточный хендовер.
